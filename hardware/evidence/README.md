# Evidências — Análise de Hardware

Esta pasta contém as evidências coletadas durante a análise das interfaces físicas do NexaSense.

## Arquivos Esperados

| Arquivo                     | Descrição                                                        |
|-----------------------------|------------------------------------------------------------------|
| `uart-boot-log.png`         | Captura de tela do monitor serial mostrando log de boot completo |
| `uart-boot-log.txt`         | Saída UART em texto (transcript completo)                        |
| `board-top.jpg`             | Foto da placa — face superior com componentes identificados      |
| `board-jtag-pins.jpg`       | Foto com pinos JTAG marcados (GPIO 12-15)                        |
| `board-uart-pins.jpg`       | Foto com pinos UART0 (TX/RX) identificados                       |
| `flash-chip-spi.jpg`        | Foto do chip W25Q32 (flash SPI) na placa                         |

## Notas

- Credenciais reais observadas na UART foram **redatadas** neste repositório.
- As fotos devem ser tiradas durante a sessão prática com o dispositivo de laboratório.
- Nenhum arquivo de evidência contém dados sensíveis em sua forma original.
